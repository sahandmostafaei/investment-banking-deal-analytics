# Security Policy

## Scope

This repository is an educational and portfolio project for investment banking analytics, financial modelling, valuation, and Python programming.

The project does not process real customer financial information, credentials, payment information, or other confidential financial data.

## Supported Versions

Only the latest version of the project on the `main` branch is actively maintained.

## Reporting a Vulnerability

If you identify a security vulnerability or an issue involving sensitive information, please report it privately to the repository owner rather than publicly disclosing the issue.

Please include:

- A description of the issue.
- Steps required to reproduce it.
- The potential impact.
- Any suggested remediation.

## Data Security

The datasets included in this repository are synthetic and illustrative.

Do not commit:

- Passwords
- API keys
- Access tokens
- Private credentials
- Confidential financial information
- Personally identifiable information
- Proprietary banking or client data

Environment variables and local secrets should be stored outside the repository.

## Disclaimer

This project is intended for educational and portfolio purposes. It is not a production financial system and should not be used to process confidential or sensitive financial information.
