# Contributing

Thank you for your interest in contributing to the Investment Banking Deal Analytics & Valuation Platform.

## Development Workflow

1. Fork or clone the repository.
2. Create a dedicated branch for your changes.
3. Install the project dependencies.
4. Make and test your changes.
5. Run the automated test suite.
6. Submit a pull request describing the changes.

## Code Standards

Contributions should:

- Use clear and readable Python.
- Follow modular design principles.
- Include appropriate documentation.
- Avoid unnecessary duplication.
- Preserve the existing project structure.
- Include tests for new analytical functionality where appropriate.

## Financial Model Changes

Changes to valuation or financial modelling logic should clearly document:

- The financial methodology used.
- Key assumptions.
- Inputs and outputs.
- Any material limitations or simplifications.

## Testing

The project uses `pytest` for automated testing.

Run:

    pytest

All existing tests should pass before submitting a pull request.

## Scope

This repository is primarily an educational and portfolio project focused on investment banking analytics, valuation, financial modelling, and Python programming.

Contributions should remain consistent with this scope.

## Disclaimer

The project uses synthetic and illustrative financial data. It is not intended to provide investment advice or professional valuation services.
